# OCC M8.5 — private beta and independent-review coordination

## Scope

This is an **access-controlled engineering preparation**, not approval for a public feature release. OCC remains off whenever `ORIRE_OCC_ENABLED` is missing or not exactly `true`. The feature also requires a server-verified Career plan and an authenticated email explicitly listed in `ORIRE_OCC_BETA_EMAILS`.

- Set `ORIRE_OCC_BETA_EMAILS` in Vercel's server-side environment as a comma-separated exact-match list (initial authorized tester: `darotudeen+career@gmail.com`). Do **not** use `NEXT_PUBLIC_` or expose the list client-side.
- A missing/empty beta allowlist denies everyone, even when the global flag is true.
- Do not set `ORIRE_OCC_ENABLED=true` in production as part of this PR. Before enabling, verify the beta account's Career entitlement, session email provenance, protected API access, all relevant user-facing feature visibility, rate limits, privacy, rollback and a controlled release authorization.
- After deployment of the code and environment variable, conduct a deliberate, separately approved internal beta smoke test; revoke the global flag immediately if an unexpected account can access OCC.
- The current access controls guard OCC server endpoints through `requireOccAccess()`. Existing UI visibility may be based only on Career plan/global feature flag; review the user-facing conditional before activation to avoid showing unavailable beta navigation to non-testers.

## Independent review orchestration

`coordinateHumanInterviewReviews(reviews, cases)` is a **deterministic report builder**. It summarizes actual distinct, submitted `HumanReview` records, per-profession coverage, missing assessments, human disagreements and independent synthetic safety-test failures.

Safe AI-assisted jobs: explain the report, prepare recruitment emails for actual practitioners, organize reviewer workload, consolidate completed assessment submissions and recommend new regression tests for confirmed discrepancies. No AI agent may invent reviewer IDs, submit ratings on behalf of real people, mark a human assessment completed, adjudicate professionally consequential claims, or approve production deployment.

The reviewer-facing nine-case pilot packets have already been generated by the owner. Store completed forms and reviewer qualification/provenance outside source control; reconcile with the private mapping for the **same** export batch. Do not upload the mapping file, names, credentials or raw candidate private information to GitHub.

## Release gates

The M8.3 release-readiness guard remains fail-closed until the actual 84 independent assessments are completed (pilot first), discrepancies adjudicated, true provenance verified, authorized provider smoke executed, privacy/consent and rollback tested and product/architecture approval recorded. AI scores are separate from human evidence. Never equate passing CI with verified career-coaching accuracy.
