# Logo

The Orire brand mark: an eight-point **burst** — four long gold points on the axes, four short violet points on the diagonals. Gold is fortune (ìre), violet is the copilot; together they read as a burst of good fortune. Built from clean intersecting blades so the points stay sharp at any size.

## Variants

- **Full colour** — gold `--gold` axes + violet `--violet` diagonals. The default, on dark or light surfaces.
- **One ink** — the whole mark in a single colour (`--ink`, or any brand colour) for stamps, engraving, and single-colour print.
- **Favicon** — below ~20px the violet diagonals thin out; drop to the gold-only burst (or one ink) so the mark stays legible.

## Lockups

- **Horizontal** — mark + "Orire" in Bricolage Grotesque 800, mark height ≈ cap height. The default.
- **Stacked** — mark centered above the wordmark, for square spaces.
- **App icon** — the full-colour mark centered on an ink tile (`#171320`), `radius-xl`.

## Rules

- **Clear space** — keep at least the width of one mark point clear on every side.
- **Minimum size** — 16px (favicon variant) / 20px (full colour).
- **Don't** — recolour the two halves arbitrarily, add a third colour, rotate the mark, stretch it, or place the full-colour mark on a busy photo (use one-ink there).
- The wordmark is always **Bricolage Grotesque 800**, tracking `-0.03em`. Don't substitute another face.
