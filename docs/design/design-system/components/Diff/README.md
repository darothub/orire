# Diff

The trust primitive. Every AI edit is shown before→after with a reason and an Accept / Reject choice — this is how fact-grounding becomes visible. Struck-through old (coral strike), green-tinted new, a "why / nothing invented" line. Reused everywhere an edit is proposed: the quality coach's single-bullet Improve, the full-CV Refine panel, and OCC's refine card. Never apply an AI change without showing this first.
