# Copilot card

How OCC renders a feature result inside the conversation. A card is the same feature data the direct surfaces use — never a chat-only reinvention — with a header (icon + title + optional match tag), a body, and at least one handoff action to the full surface. Variants: match analysis (shown here), refine summary, template picker, cover-letter draft, recommended-next. Keep cards ≤ 420px so they sit naturally in a bot bubble.
