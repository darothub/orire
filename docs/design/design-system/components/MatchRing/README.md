# Match ring

The signature element and the one orchestrated motion moment: the ring fills (stroke-dashoffset) while the number counts up, ~1.3s ease-out. **Gold** for a resting "best current match"; **match green** for a fresh simulation result. Bricolage numeral at the center with a small "match" label. Reused at 78px inside Copilot cards. Honor `prefers-reduced-motion` by jumping to the final value.
