# Button

The primary way to act. Three variants carry intent: **primary** (violet) for the main action in a view, **gold** reserved for the match/refine payoff action, **ghost** for secondary choices. Verb-first, sentence case ("Simulate the gap"). At most one primary and never more than one gold per view. `.or-btn-sm` for dense contexts. Hover lifts 1px; focus shows a 2px violet ring.
